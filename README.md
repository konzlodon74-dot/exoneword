## The word

**Unsubscribed**

A relationship treated like a service you cancelled — no drama, no
shouting, just quietly opted out. Everyone has hit "unsubscribe" on
something that stopped being worth the inbox space.

## How it works

`main.py` (Python 3, no dependencies, no network) validates the word
(exactly one word, 1–111 characters) and writes it, and nothing else,
to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
